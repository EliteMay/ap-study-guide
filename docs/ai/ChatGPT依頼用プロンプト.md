# ChatGPT依頼用プロンプト

このファイルは `EliteMay/ap-study-notes` をChatGPTで直接開発するときの依頼例です。
GitHubへ接続できる場合はZIP不要です。

---

## 1. 通常の改修

```text
GitHubの EliteMay/ap-study-notes を確認して修正してください。

目的:
【ここに目的】

要望:
【ここに欲しい機能や直したい点】

README、仕様書、作業報告書の必要な箇所を確認して、GitHubへ直接反映してください。
現在の構成を守ることより、操作性・分かりやすさ・学習効果・軽量さ・保守性を優先してください。
ただし進捗消失やデータ破損につながる変更は移行を考慮してください。
```

---

## 2. UIを大きく改善

```text
EliteMay/ap-study-notes のUIを大きく改善してください。

目的:
【例: 辞書っぽさを減らして、毎日学習しやすいダッシュボード型にしたい】

今のレイアウトやファイル構成に縛られなくて構いません。
必要ならHTML/CSS/JSの構成も整理してください。

条件:
- GitHub Pagesで使えること
- 操作が分かりやすいこと
- 重くしすぎないこと
- スマホでも致命的に崩れないこと
- 既存の学習進捗を消さないこと
- README、仕様書、作業報告書も更新すること
```

---

## 3. 用語解説改善

```text
EliteMay/ap-study-notes の次の分野を改善してください。

分野:
【セキュリティ / ネットワーク / データベース】

対象:
【カテゴリ、用語、IDなど】

目的:
初心者が意味だけでなく、仕組み・具体例・試験での出方・似た用語との違いまで理解できるようにする。

必要なJSONを直接修正し、構文・ID・マニフェストとの整合も確認してください。
作業報告書も更新してください。
```

---

## 4. 新しい単元

```text
EliteMay/ap-study-notes に【単元名】を追加してください。

まず要件を整理してください:
- 目的
- 必要機能
- 画面構成
- データ構成
- 保存方法
- 既存データへの影響
- 完成条件

重要な曖昧さがなければ、そのままGitHubへ実装してください。
今の単元ページ構成を無理にコピーする必要はありません。
既存より良い設計があれば採用してください。
```

---

## 5. テスト機能改善

```text
EliteMay/ap-study-notes のテスト機能を改善してください。

欲しい機能:
【例: ランダム / 順番 / 苦手だけ / 次から出さない / 正答率】

今の test.html の構造は必要なら作り直して構いません。
問題データが増えるならJSON分離してください。
既存進捗を使う場合はlocalStorageとの整合を確認してください。
```

---

## 6. 過去問追加・改善

```text
EliteMay/ap-study-notes の過去問を追加または改善してください。

対象:
【年度・期・問番号】

PDF原本、問題文JSON、解説JSON、索引を確認してください。
現在の problemFile / sourceProblemFile / targets / answerTargets の対応を確認し、必要なら構造改善も可能です。
ただし既存問題が壊れないように移行してください。
```

---

## 7. 不具合修正

```text
EliteMay/ap-study-notes で次の不具合を直してください。

症状:
【症状】

再現条件:
【分かる範囲】

原因をGitHub上のコードから調べて、必要な関連ファイルを直接修正してください。
現在の実装に継ぎ足すより作り直した方が安全なら、その判断もして構いません。
確認できなかった実ブラウザ動作は未確認として残してください。
```

## 8. GitHub Pages確認

```text
EliteMay/ap-study-notes をGitHub Pagesで安定して使えるか確認してください。

確認してほしいもの:
- index.html
- CSS / JS
- JSON fetch
- PDFリンク
- 相対パス
- .nojekyll
- スマホ表示

必要な修正はGitHubへ直接反映してください。
```

## 9. 全体を100点に近づける

```text
EliteMay/ap-study-notes の現在の状態を確認してください。

このサイトを40点としたとき、100点に近づけるために必要な改善を、
操作性・学習効果・分かりやすさ・軽量さ・保守性・見た目の順で考えてください。

小さな継ぎ足しだけでなく、必要なら画面構成・機能・データ設計も見直してください。
重要な仕様変更で確認が必要なもの以外は、そのまま実装まで進めてください。
```

## 10. Codexを使う場合

基本的には不要です。

実機確認が必要なときだけ、例えば次のように依頼します。

```text
EliteMay/ap-study-notes の現在のGitHub版を基準に、実ブラウザで次を検証してください。

確認内容:
【検索、保存、レスポンシブなど】

問題があれば原因と必要な修正を整理してください。
```
