# 今回の目的

サイトを「機能が多いが進捗を信用しにくい状態」から、**現在の理解度・復習期限・主要導線・データ保全を重視する学習アプリ**へ修正する。

主対象:

1. 習得判定
2. Runtime二重化
3. 記述自己採点の抜け穴
4. 13Unit Hub分裂
5. Home / Sidebar過密
6. localStorage消失対策
7. Browser E2E不足
8. 不要な`no-store`

# 今回変更した内容

## 1. 習得判定を厳格化

新規: `js/study-state.js`

- Lessonは全問回答 + 75%以上で理解確認。
- ChoiceはBestだけでなく最近の結果・最新結果を使う。
- Writtenは最新自己評価を重視。
- 14日経過後は復習期限として扱う。
- Best Scoreは履歴表示用で、現在理解と分離。

既存localStorageは削除していない。

## 2. 記述の空欄自己採点を防止

- Short Practice: 12文字以上書かないとModel Answerを開けない。
- Long Case: 20文字以上書かないとModel Answerを開けない。

対象:

- `js/practice.js`
- `js/cases.js`

## 3. Loaderを統一

新規:

- `js/lesson-data.js`

更新:

- `js/practice-data.js`
- `js/case-data.js`
- `js/mock-data.js`

Lesson / Practice / Case / MockはManifest正本から読む。旧37問Snapshotは通常Runtimeから直接読まない。主要Loaderで同一Requestをmemoizeし、`cache:'no-store'`常用も削減。

## 4. 13Unit Hubを統一

`json/curriculum/ap-2026-coverage.json`の全13Unitを、

`unit.html?unit=<unitId>`

へ統一。

旧専用Hubは削除せず、旧用語辞書・互換層として残す。汎用Unit Hubから必要時のみ「旧用語辞書」へ進める。

## 5. Homeを整理

旧Homeの重複導線を減らし、以下へ整理。

1. 今日やること
2. 13Unit
3. 演習・本番・管理

「今日やること」は復習期限 / 要復習を未着手より優先する。

## 6. Shared Navigationを整理

22項目前後のフラット表示から、

- 学習
- 演習
- 本番・管理

へグループ化。

Mobileでは閉じたSidebarを`inert` + `aria-hidden`にした。Escape CloseとFocus Restore、Skip Linkも追加。

## 7. Backup / Restoreを追加

新規:

- `html/data.html`
- `js/data-tools.js`
- `css/data-tools.css`

機能:

- 学習履歴JSON Export
- Backup JSON Import
- 認識済みKeyのみRestore
- 全削除は二重確認

## 8. 進捗Dashboardを現在状態基準へ変更

`js/progress.js`を`APStudyState`へ統一。

表示状態:

- 未着手
- 要復習
- 理解確認済み
- 復習期限

Best Scoreだけで「理解済み」にならないよう変更。

## 9. CIを強化

新規:

- `tests/validate-runtime-quality.mjs`
- `tests/e2e-smoke.mjs`

既存Validatorもr16構造へ更新。

Runtime Quality Validatorでは、

- Centralized Loader
- 旧37問Runtime非使用
- Strict Mastery
- Unified Hub
- Backup / Restore
- Compact Navigation
- Mobile inert

を検証する。

## 10. Playwright Browser Smokeを導入

`.github/workflows/validate.yml`でChromiumをInstallし、HTTP Server上で実ブラウザ操作する。

Smoke対象:

- Home
- Security Unit Hub
- Lesson誤答 → Masteredにならない
- Written Practice空欄Guard
- Long Case空欄Guard
- Mobile Menu / inert / Escape
- Backup Page

## 11. E2Eで実際に見つかった不具合

初回E2EではMobile Menu clickが失敗。

原因:

- 画面外へ移動したSkip Linkがpointer event領域を残し、Mobile Menu buttonを覆っていた。

修正:

- 非Focus時のSkip Link pointer eventを無効化し、Focus時だけ有効化。

これは静的Validatorでは検出できず、Browser Smokeを追加したことで発見できた実UI不具合。
