# 主要な過去履歴

## 2026-05-20 セキュリティ単元の整理

### 主な内容

- 情報セキュリティ用語501件・詳細解説501件のJSON構成を整理。
- HTMLへの大量直書きを避け、用語JSONと詳細解説JSONを分離。
- 過去問の問題文と解説を分離。
- 問題文を `json/past-problems/`、解説を `json/past/` に配置。
- 過去問解説を設問単位の `sections` で管理。
- JSON品質チェック用 `tools/check-json.html` を整備。

### 過去に起きた問題

- 実在しないJSONパスを参照していた。
- 過去問件数表示と実データがずれた。
- 用語解説にテンプレート文の使い回しが多かった。
- 問題文と解説の役割が混ざっていた。

### 今後も有効な注意

- 用語件数だけでなく、terms/detailsのID対応を見る。
- 過去問は問題文側 `targets` と解説側 `answerTargets` を比較する。
- 解説は長さより、その用語固有の具体性を優先する。

## 変更した考え方

- Codexが最終反映・検証。

- GitHubを正本にする。
- ChatGPTが直接読み書きする。
- Codexは特殊な実行確認だけ。
- 現在のUI・構成・JSON設計は変更可能。

## それでも注意するもの

現状維持のためではなく、利用データを守るため次は慎重に扱う。

- localStorageの学習進捗

- 過去問ID
- JSON間参照
- PDFと過去問データの対応
- URLハッシュ

必要なら移行処理を入れたうえで変更可能。

## 今回変更していないもの

- 学習用語JSON本体
- 過去問JSON本体
- `index.html`
- 各単元HTML
- `css/style.css`

今回はGitHub移行と開発方針の整理が中心。
