# 6. Security 501語 全件監査

今回の大バッチで最後の巨大旧教材Security 501語を全件監査した。

|---|---:|

| Network | 104 |
| Computer Systems | 13 |
| Law / Standards | 10 |

重要な整理:

- LAN/IP/CIDR/DNS/TCP/UDP/HTTP/Mail/VPN等の純粋な通信基礎 → Network
- IaaS/PaaS/SaaS/Serverless等 → Computer Systems
- 法律・個人情報・著作権・NDA等 → Law
- 構成管理・変更管理 → System Development
- SLA → Service Management
- Security監査・内部統制 → Audit

これにより、SecurityにもDNS説明、NetworkにもDNS説明という二重主教材を解消した。
