### 3. 118 / 118 Lesson直接Coverageを必須化

`tests/validate-practice.mjs`

追加・変更:

- Practice総数をValidatorへ91などの旧固定値で持たずManifestから検証。
- 13/13 Unitを維持。
- 23/23中分類を維持。
- **118 / 118 Lessonすべてが少なくとも1短問から直接参照されることを必須化。**
- Coverage Bankは `PC-` ID、1問1Lesson、Choiceの `mockEligible:false` を検証。

これにより、今後Lessonを追加したのにPractice参照を忘れた場合はCIで失敗する。

### 4. Mockへの混入を防止

短問全体を91→139へ増やすと、従来の `js/mock-data.js` は全Choiceを科目A候補にしていたためMock構成を壊す。

対策:

- Coverage追加Choice 36問へ `mockEligible:false` を設定。
- `js/mock-data.js` は `type === 'choice' && mockEligible !== false` のみMock候補にする。
- 既存Practice Choice 57 + Mock専用23 = **80問** を維持。

`tests/validate-mock.mjs` で次をRegression Guardする。

- Mock対象Practice Choice = 57
- Mock専用 = 23
- 合計 = 80
- Coverage Choiceが明示的に除外されている

### 5. Progressの固定91依存を除去

`tests/validate-progress.mjs`

Practice / Case件数を各Manifestから集計するよう変更。短問増加時に旧91へ依存してCIが壊れる構造を除去した。

### 6. Browser Smoke更新

旧r19 Smokeは「直接短問がないLessonを実Dataから1件探し、Fallbackを確認」していた。

r20では118/118になったため前提を反転。

新Smoke:

1. Lesson Index 118件をBrowserから読む。
2. Practice Manifest全Fileを読む。
3. 直接参照されないLessonが0件であることを確認。
4. `ALG-01` を開く。
5. Lesson内の `PC-ALG-01` 直接導線が表示されることを確認。
6. LinkをClickし、短問画面で「擬似言語のトレース」が実際に表示されることを確認。
7. Coverage済みLessonでFallbackが誤表示されないことを確認。

途中CIで旧Smokeが `expected at least one lesson without direct practice reference` となり失敗したが、これは実装不具合ではなく旧テスト前提がr20仕様と矛盾したため。上記へ更新した。
