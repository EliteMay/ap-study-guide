## 2026-05-21 v17 過去問リンク修正確認

### 依頼内容

- `応用_過去問リンク修正_v17.zip` の中身を確認し、過去問解説から用語詳細へ移動できない問題の修正を反映する。

### 原因

- `security-past.html` は `security.html#用語ID` のリンクを生成していた。
- しかし `security.html` の用語カードはJSON読み込み後にJavaScriptで生成されるため、ブラウザ標準のハッシュ移動時点ではリンク先要素がまだ存在しない。
- そのため、用語カードまで再スクロールされず、単語一覧付近に残ることがあった。
- 関連語に対応する辞書IDが見つからない場合、`href="#"` が出るとページ上部へ誤移動する可能性があった。

### 修正したこと

- `security.html` に、JSON描画後のハッシュ再処理を追加した。
- `security.html#用語ID` で開いたとき、検索条件とカテゴリ絞り込みを解除し、該当カードを表示して詳細解説を自動で開くようにした。
- 該当カードに強調表示を付け、リンク先が分かるようにした。
- `hashchange` に対応し、同じページ内の用語リンクでも再処理できるようにした。
- `security-past.html` の関連語リンクで辞書IDが見つからない場合は、`href="#"` ではなく未登録表示にした。
- `README.md` と `仕様書.md` に、ハッシュリンクと未登録関連語の扱いを追記した。

- 明確な構造不備、JSON件数ズレ、ID不一致は見つからなかった。
