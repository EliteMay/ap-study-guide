## 発見した問題

- 旧12カテゴリがすべて**40語固定**で、必要性より件数合わせの影響が強かった。
- 基礎概念と補助的な細部が同じ重要度で並んでいた。
- TLS、DNSSEC、FW、IDS/IPS/WAF、SPF/DKIM/DMARC等がSecurityと重複する。
- SLAとインシデント管理はNetworkではなくサービスマネジメントが主所属。
- サブネット、routing、TCP、DNS、障害切り分けは単語カードでは問題解法へつながりにくかった。

```json
    {"prefix":"net-dns-","from":1,"to":40}
  ]
}
```
