# 6. 今回: Computer Systems 中分類3〜6の実教材化

旧用語監査終了後の次段階として、IPA大分類2「コンピュータシステム」の中分類3〜6をまとめて教材化した。

目的:

- CPU部品名の暗記ではなく、命令が実行される流れを追えるようにする。
- Cache / Virtual Memory / Scheduling / Reliability等を式と状態で理解する。
- System構成を構成図で判断できるようにする。
- Hardwareを単なる名称一覧ではなく、Dataの入出力方向と役割で理解する。

既存CMP-01/02は維持し、新規CMP-03〜12を追加した。

## CMP-01

`コンテナと仮想化の基本`

- Container / VM
- Image / Runtime
- CI/CDとの接点

## CMP-02

`クラウドサービスモデルと責任分界`

- IaaS / PaaS / SaaS
- Serverless
- Cloud Storage / Object Storage
- Provider / Customer責任境界

## CMP-03

`CPU・命令実行・レジスタ・パイプライン`

追加内容:

- Fetch → Decode → Execute → Memory → Write Back
- PC / IR / General Register
- ALU / Control Unit
- Pipeline
- Data / Control / Structural Hazard
- RISC / CISC

Clock周波数だけで性能を判断しないよう、CPI・命令数との接続を明記した。

## CMP-04

`メモリ階層・キャッシュ・仮想記憶`

追加内容:

- Register → Cache → Main Memory → SSD/HDD
- Hit / Miss / Hit Ratio / Locality
- Cache実効Access時間
- Virtual Address / Page / Frame
- Page Table / TLB
- Page Fault
- LRU / FIFO

例題:

Cache 2ns、Main Memory 50ns、Hit率90%、Miss時にCache確認後Main Memoryへ行く条件で平均Access時間 **7.0ns** を計算する。

## CMP-05

`バス・入出力・割込み・DMA`

追加内容:

- Data / Address / Control Bus
- I/O Controller
- Polling
- Interrupt
- DMA
- PCI Express / USB / SATA / HDMI等

PollingとInterruptを「CPUが待つか、Deviceから通知されるか」で比較した。

## CMP-06

`OS・プロセス・スレッド・スケジューリング`

追加内容:

- Process / Thread
- Ready / Running / Waiting
- FCFS
- Round Robin
- Priority Scheduling
- Context Switch
- Critical Section
- Mutex / Semaphore
- Deadlock

Round Robin例題:

A=5ms、B=3ms、C=2ms、Time Quantum=2ms

CPU順:

`A → B → C → A → B → A`

## CMP-07

`システム構成・3層構成・クラスタ・負荷分散`

追加内容:

- Presentation / Application / Dataの3層
- Scale up / Scale out
- Load Balancer
- Active-Standby
- Active-Active
- Shared Nothing
- Server Session / Shared Session Store / Stateless

## CMP-08

`CPU・システム性能を式で読む`

追加内容:

- Clock Frequency
- Clock Period
- CPI
- CPU実行時間
- MIPS
- Response Time
- Throughput

例題:

2GHz、4×10^8命令、平均CPI=2

`CPU time = 4×10^8 × 2 / 2×10^9 = 0.4秒`

2.5GHzの1cycle時間 = **0.4ns**。

## CMP-09

`信頼性・可用性・MTBF/MTTR・冗長化`

追加内容:

- Reliability
- Maintainability
- Availability
- MTBF / MTTR
- 直列系 / 並列系
- Failover / Failback
- Fault Tolerance
- Hot / Cold Standby

例題:

MTBF=990h、MTTR=10h

`A = 990 / (990 + 10) = 0.99 = 99%`

Reliability 0.9の2台を並列にすると、少なくとも1台動けばよい条件で **0.99**。

## CMP-10

`ストレージ・RAID・ファイルシステム`

追加内容:

- HDD / SSD
- RAID 0 / 1 / 5 / 6
- Striping / Mirroring / Parity
- File System
- Metadata / Block allocation
- Journaling

例題:

2TB Disk × 4台、RAID 5 → **6TB**。

RAIDはBackupの代替ではないことも明記した。

## CMP-11

`ミドルウェア・開発ツール・OSS`

追加内容:

- Hardware → OS → Middleware → Application
- Web Server / Application Server
- Compiler / Interpreter / Runtime / Linker
- Debugger / Profiler / Build Tool / Package Manager / Version Control
- OSS License / Support / Update / Project継続性

## CMP-12

`ハードウェア・入出力デバイス・センサ`

- Input / Output / Storage / Network I/O
- GPU / CPU
- UPS
- Surge Protection
