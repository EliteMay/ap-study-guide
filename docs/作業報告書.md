## Guide 1.7.0との差分

AP Study Notesへ直接影響する新しい主要要件:

1. `PROJECT_LEARNINGS.md` を持ち、高コストBug・重要成功を長期Memoryとして残す。
2. DATA / TOOL等のInteractive ProjectではDevelopment Diagnosticsを持つ。
3. DiagnosticsはLocal-first、上限付きで、Secret / Token / User入力全文をLogへ残さない。
4. 中規模Interactive ProjectではDiagnostic Export / Copy Reportを用意する。
5. Import / Restore / Storage Failure等の重要な失敗を診断できるようにする。
6. PUBLIC-CONTENTでLanguage / title / Metadata / Privacyを確認する。
7. Direct Linkが多いGitHub Pagesでは404 Recoveryを条件付きで検討する。
8. Cleanup後の最終CommitでStatic / Browser / Pagesを確認する。
9. AI生成Codeも通常の品質Gateを通す。

Guide 1.7.0にはVisual Design Review / AGENTS.md等も追加されているが、Compatibilityで**既存ProjectへVisual Layout変更・AGENTS.md追加を強制しない**と明記されている。今回は既存UIを全面変更せず、直接不足している項目を適用した。
