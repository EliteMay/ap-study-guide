## 2026-08-29 旧実装監査・第1回大整理

### 見つけた主な問題

- `security.html` / `network.html` / `database.html` が同じ検索・進捗・詳細JSを個別コピーしていた。
- `security.html` に動作していない旧過去問UI/JS/CSSが残っていた。
- ネットワークに `sec-` フォールバックIDなどコピペ残骸があった。
- ホームの公開中件数等に固定値のズレがあった。
- `tools/check-json.html` がDBを検査していなかった。
- `html/template.html` が大量HTML直書き方式の旧設計だった。
- 旧テストが約72語をHTML内へ別管理し、正式1210語と同期していなかった。
- 過去問HTMLが大きなインラインCSS/JSを持ち、古いフィールド世代差も吸収できていなかった。

### 実施

- `js/term-page.js` / `css/term-page.css` を追加し3用語ページを共通化。
- 用語ページHTMLを約26〜32KBから約5KB前後へ縮小。
- セキュリティ用語ページの死んだ過去問機能を削除。
- ホームを `js/home.js` / `css/home.css` へ分離。
- `tools/check-json.html` を3分野 + 過去問targets比較へ拡張。
- `html/template.html` をJSON + 共通エンジン方式へ更新。
- 旧テストを `html/test-legacy.html` へ完全退避。
- 新 `html/test.html` / `js/test.js` / `css/test.css` を正式JSON直結へ変更。
- `js/past.js` / `css/past.css` を追加し過去問ページを外部化。
- `studyChecklist` / `reviewChecklist`、複数choices形式を表示側で吸収。

### ☆ 復習リスト

3分野の用語カードへ `☆ 復習` を追加。

機能:

- 追加/解除
- 3分野共通保存
- 用語ページで復習だけ絞り込み
- ホームで件数表示
- ホームで分野別内訳表示
- テストの出題元として利用
- `?bookmarks=1` で用語ページを復習絞り込み初期表示可能

保存キー:

`ap-study-bookmarks-v1`

### 復習リストテスト

`html/test.html` に `☆ 復習リスト` を出題元として追加。

- `?source=bookmarks` で復習モードを初期選択。
- 復習リストが空の場合は開始ボタンを無効化し、追加方法を表示。
