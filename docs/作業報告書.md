# r17 今回の主作業

## 1. 単語機能の役割を変更

旧サイトでは用語カードが主教材だったが、現在の主教材は構造化Lesson・短問・長文Case・模試へ移っている。

そのため旧6分野の単語解説を「各分野ページの主役」として残すのではなく、**補助辞書**へ再定義した。

新規:

- `html/glossary.html`
- `js/glossary.js`
- `css/glossary.css`
- `tests/validate-glossary.mjs`

対象:

- Algorithm 65
- Database 229
- Network 480
- Security 501
- System 75
- Management 72
- Total **1,422**

## 2. Glossaryの軽量化

旧ページのように全用語カードを同時描画しない。

実装:

- 全文検索
- Domain Filter
- Category Filter
- Bookmark Filter
- Checked / Unchecked Filter
- 60件ずつ表示
- Load More
- `?q=` / `?domain=` / `?term=`
- Bookmark Toggle
- Checked Toggle
- Detail Expand

Security / Network / Databaseは既存Details ManifestからCategoryの詳細JSONを解決し、**詳しい解説を開いた時だけLazy Load**する。

Detail FileはMapでmemoizeする。

Algorithm / System / Managementは基本定義から補足を出し、旧ページへのLinkを残す。
