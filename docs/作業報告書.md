## ALG-03 実装済み

**配列・リストとデータの持ち方**

Data:

`json/lessons/algorithm/alg-03-array-list.json`

置換対象:

- term-alg-014 配列
- term-alg-015 リスト
- term-alg-016 連結リスト
- term-alg-017 双方向連結リスト

今回の改善:

- 配列と単方向連結リストを同じ値で図示。
- 配列の添字アクセスがO(1)になる理由を説明。
- 配列途中挿入で後続要素を移動する状態図を追加。
- 連結リスト途中挿入で参照を変更する前後図を追加。
- 「連結リストの挿入は常にO(1)」という雑な暗記を禁止し、位置探索が必要なら全体O(n)になり得ることを明記。
- 双方向 / 循環リストを派生構造として比較。
- 動的配列 / 多次元配列を不足範囲としてLesson内に追加。
- 7問の確認問題を追加。
