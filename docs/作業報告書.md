# 7. 2026 CBTの公式方針確認

IPAの2026年度案内を確認。

確認内容:

- ペーパー方式からCBT方式へ変更。
- 旧「午前試験」は「科目A試験」。
- 旧「午後試験」は「科目B試験」。
- 問う知識・技能の範囲、出題形式、出題数・解答数、採点方式、配点、合格基準、試験時間は変更なし。
- **2026年度CBTの実際の試験問題は非公開。第三者開示も禁止。**

したがって、2026実問題を「過去問」として収集・再現する設計にはしない。
