# AP Study Notes 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の個人学習用静的Webアプリ。

- 正本: GitHub `EliteMay/ap-study-notes`
- 主利用環境: GitHub Pages
- 構成: HTML / CSS / JavaScript / JSON / PDF
- BUILD: `2026.08.29-r5`
- 状態: **機能基盤は利用可能 / 教材内容は再設計中**

ページ数・用語数だけでは教材完成としない。

## 2. 目的と優先順位

AP合格に必要な知識を、単語暗記だけでなく計算・図・コード・SQL・ケース問題まで含めて理解し、問題へ適用できる状態にする。

優先順位:

1. 操作性
2. 分かりやすさ
3. 軽量性
4. 保守性
5. 見た目

## 3. 崩してはいけない仕様

- 既存用語IDと進捗対応を不用意に壊さない。
- localStorageキー変更時は移行処理を用意する。
- 過去問PDF / 問題JSON / 解説JSONの対応を壊さない。
- GitHub Pagesの相対パスを壊さない。
- 秘密情報/APIキーを公開リポジトリへ置かない。
- 監査前の大量削除・大量ID変更をしない。
- 旧用語の移行完了とシラバス範囲の最終完成を混同しない。

## 6. 構造化Lesson

主教材は内容に応じて構造化Lessonを使用する。

- `html/lesson.html`
- `js/lesson.js`
- `css/lesson.css`
- `json/lessons/lesson-index.json`
- `json/lessons/<unit>/*.json`

URL:

`html/lesson.html?id=<LESSON_ID>`

基本meta:

- `id`
- `title`
- `unitId`
- `officialMiddleCodes[]`
- `qualityStatus`
- `legacySource`
- `legacyTermIds[]`
- `estimatedMinutes`

本文:

- `intro`
- `objectives[]`
- `sections[]`
- `checks[]`
- 必要時 `next[]`

現在のrenderer:

- `text`
- `comparison`
- `diagram`
- `code-trace`
- `steps`
- `mistakes`
- `worked-example`（renderer実装済み。現行49Lessonでは既存のCI許可形式を中心に使用）

Lessonナビは同じ `unitId` 内を `order` 順で前後移動し、別ユニットは明示リンクで接続する。

現在 **49Lesson**。
