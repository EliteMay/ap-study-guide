# AP Study Notes 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の個人学習用静的Webアプリ。

- 正本: GitHub `EliteMay/ap-study-notes`
- 主利用環境: GitHub Pages
- BUILD: **`2026.08.30-r17`**
- 基準: IPA 応用情報技術者試験 シラバス Ver.7.2
- 技術: HTML / CSS / JavaScript / JSON / PDF
- Server必須機能・秘密情報なし

現在は **旧1,422語監査完了 / 118Lesson / 短問91問 / 長文16Case48設問 / 科目A・B 150分模試 / 2025春秋公開午後22大問Lesson Mapping / 統合単語辞書 / Action-first Home** の段階。

## 2. 目的

1. Homeから目的をすぐ選べる。
2. 13Unitから体系的に学ぶ。
3. 構造化Lessonで仕組みを理解する。
4. 短問・長文Case・模試で取り出す。
5. 最新公開公式問題へ接続する。
6. 分からない用語は統合辞書で即時検索する。
7. 進捗Dashboardから弱点へ戻る。
8. 学習データをBackupできる。

優先順位: **操作性 → 分かりやすさ → 軽量性 → 保守性 → 見た目**。

## 3. Home

Page: `index.html`
Runtime: `js/home.js`
Style: `css/home.css` + `css/home-launch.css`

Homeは詳細Dashboardではなく「行動選択ランチャー」とする。

主要Action:

- Lesson
- 単語辞書
- 短問
- 長文Case
- 150分模試
- 公式公開問題
- 学習進捗
- 学習データ

`#home-quick-search` は機能名・13Unit名を候補表示し、候補にない語も `html/glossary.html?q=<QUERY>` へ送る。

Homeに残す学習状態は以下だけ。

- Lesson理解確認数
- 短問理解済み数
- Case理解済み数
- 模試回数
- 今日の優先項目

詳細分析は `html/progress.html` の責務とする。

### 4.2 機能

- 全文検索
- Domain Filter
- Category Filter
- Bookmark Filter

- 60件ずつ表示
- `?q=` 検索
- `?domain=` Domain指定
- `?term=` 用語Direct Link
- 詳細展開
- Bookmark Toggle
- Checked Toggle
- 旧ページDirect Link

### 4.3 Performance

1,422用語の索引Dataは辞書Pageでまとめて検索対象にしてよいが、**1,422カードを一括DOM生成しない**。

`PAGE_SIZE = 60` とし、表示範囲だけDOM生成する。

Security / Network / Databaseの詳細JSONは、用語を開くまで読まない。Category→Detail FileをDetails Manifestから解決し、ファイル単位でmemoizeする。

- `security-details-manifest.json`
- `network-details-manifest.json`
- `database-details-manifest.json`

Algorithm / System / Managementは定義を基に基本補足を表示し、必要なら旧ページへ移動できる。
