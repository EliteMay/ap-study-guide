# AP Study Notes 仕様書

## 1. 概要

応用情報技術者試験（AP）の個人学習用静的Webアプリ。

GitHubリポジトリ `EliteMay/ap-study-notes` を正本とする。HTML/CSS/JavaScript/JSON/PDFのみで動作し、GitHub Pagesを主な利用環境とする。

既存構成の維持自体を目的にせず、操作性・分かりやすさ・軽量性・保守性が改善する場合は再設計してよい。

## 2. 学習フロー

基本フロー:

1. 用語を検索・カテゴリから探す
2. 短い定義と詳細解説を読む
3. まだ怪しい用語へ `☆ 復習`
4. 理解できた用語へ `✓ 習得済み`
5. 復習リストまたは分野指定でテスト
6. セキュリティ午後過去問で実戦確認
7. ホームDashboardから続きへ戻る

## 4. 共通アプリシェル

- CSS: `css/shell.css`
- JS: `js/shell.js`
- BUILD: `2026.08.29-r3`

仕様:

- PCでは左固定サイドバー。
- 920px以下では上部バー + ドロワーサイドバー。
- safe-areaを考慮する。
- `Esc` でドロワーを閉じる。
- `/` キーでページ内の検索ボックスへフォーカスする。
- ライト/ダークテーマを切り替えられる。
- テーマは `ap-study-theme` に保存する。
- 共通トースト通知を提供する。
- サイドバーにBUILDを常時表示する。
- `prefers-reduced-motion` を尊重する。

`window.APStudyUI` が共通状態APIを提供する。

主なAPI:

- `toast(message)`
- `recordRecent(item)`
- `getRecent()`
- `getBookmarks()`
- `saveBookmarks(items)`
- `theme.get()` / `theme.set()`

## 5. Dashboard

- HTML: `index.html`
- CSS: `css/home.css`
- JS: `js/home.js`

表示:

- 学習単元数
- 公開中単元数
- 習得済み総数
- 復習リスト件数
- 最後に見た用語から「続きから」
- 最近見た用語 最大5件
- 復習リストの分野別内訳
- 3分野の進捗
- 過去問件数

件数はHTMLへ固定せず、manifest・DOM・localStorageを基準にする。

## 7. 用語データ

### 軽量用語

`json/terms/*.json`

主なフィールド:

`id`, `term`, `aliases`, `category`, `definition`

### 詳細解説

`json/details/*.json`

主なフィールド:

`id`, `term`, `category`, `level`, `tags`, `beginner`, `example`, `examPoint`, `trap`, `deepDive`, `relatedConcepts`, `commonMistakes`, `afternoonUse`, `howToRemember`

terms/detailsは `id`・`term`・`category` を対応させる。

|---|---:|---:|
| 情報セキュリティ | 501 | 501 |
| ネットワーク | 480 | 480 |
| データベース | 229 | 229 |

## 8. 保存データ

| 用途 | localStorageキー |
|---|---|
| セキュリティ習得 | `security-terms-checked` |
| ネットワーク習得 | `network-terms-checked` |
| DB習得 | `database-terms-checked` |
| 復習リスト | `ap-study-bookmarks-v1` |
| 最近見た用語 | `ap-study-recent-v1` |
| テーマ | `ap-study-theme` |

復習リストは3分野共通で、概ね次の情報を持つ。

- `id`
- `term`
- `category`
- `domain`
- `subject`
- `href`
- `updatedAt`

最近見た用語は最大12件保持する。

IDまたは保存キーを変更する場合は、既存進捗の移行を検討する。

## 9. テスト

- HTML: `html/test.html`
- CSS: `css/test.css`
- JS: `js/test.js`

出題データは3分野の正式軽量用語JSON。

機能:

- 3分野ミックス
- 分野指定
- ☆ 復習リストだけ出題
- 最大100問
- 説明→用語
- 用語→説明
- ミックス
- 同カテゴリ中心の誤答候補
- 正解語/別名の自動マスク
- 1〜4キー回答
- Enterで次へ
- 間違い一覧
- 間違いだけ再テスト
- 辞書カードへのリンク

復習リストモードでは正解対象だけを復習リストから選び、誤答候補は全正式辞書から取得して難易度低下を抑える。

`?source=bookmarks` で復習リストモードを初期選択できる。

## 10. セキュリティ過去問

- HTML: `html/security-past.html`
- CSS: `css/past.css`
- JS: `js/past.js`
- 索引: `security-past-index.json`
- 問題文: `json/past-problems/`
- 解説: `json/past/`
- PDF: `sources/`

対応ルール:

- 索引 `file` → 解説JSON
- 索引 `problemFile` → 問題文JSON
- 解説 `sections[].answerTargets`
- 問題文 `problem.questions[].targets`

同じ設問ラベルでtargetsを一致させる。

互換:

- `studyChecklist` / `reviewChecklist` 両対応
- choicesの文字列/オブジェクト形式両対応
- `answerGuide` 不足時はsectionsから最低限表示
- 問題文JSON読込失敗時も解説/PDFを可能な範囲で表示

## 11. 品質チェック

### 開発用チェック画面

`tools/check-json.html`

### 自動ブラウザテスト

`tests/data-integrity.test.html`

ASMRTubeのtests分離方式を参考に、サイト本体と検査画面を分離する。

自動テスト対象:

- 各term/detail JSONのfile count
- manifest総数
- 用語ID重複
- 用語名重複
- term/detail ID対応
- term/category対応
- 過去問解説件数
- problemFile存在
- sections存在
- 解説 `answerTargets` と問題 `targets` の一致
- 答案情報存在
