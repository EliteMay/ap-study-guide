# AP Study Notes 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の個人学習用静的Webアプリ。

- 正本: GitHub `EliteMay/ap-study-notes`
- 主利用環境: GitHub Pages
- 構成: HTML / CSS / JavaScript / JSON / PDF
- BUILD: `2026.08.29-r5`
- 状態: **機能基盤は利用可能 / 教材内容は再設計中**

ページ数・用語数・動作だけでは教材完成としない。

## 2. 目的と優先順位

目的は、AP合格に必要な知識を単語暗記ではなく、計算・図・コード・SQL・ケース問題まで含めて理解し、問題へ適用できる状態にすること。

優先順位:

1. 操作性
2. 分かりやすさ
3. 軽量性
4. 保守性
5. 見た目

教材はGitHub上のJSON、個人進捗はlocalStorageへ保存する。

## 3. 崩してはいけない仕様

- 既存用語IDと進捗対応を不用意に壊さない。
- localStorageキー変更時は移行処理を用意する。
- 過去問PDF / 問題JSON / 解説JSONの対応を壊さない。
- GitHub Pagesの相対パスを壊さない。
- 秘密情報/APIキーを公開リポジトリへ置かない。
- 監査前の大量削除・大量ID変更をしない。

## 6. 監査action

監査JSONでは基本的に以下のactionを使う。

- `keep-core`: Lessonの主要学習項目として残す。
- `keep-supporting`: 比較・補足・演習で扱う。
- `merge-into-lesson`: 単独長文カードにせず上位Lessonへ統合する。
- `move-primary-unit`: 主教材を別の13学習ユニットへ移す。

既存IDはLesson移行中も維持する。

## 11. 構造化Lesson

主教材は用語カードではなく必要に応じて構造化Lessonを使用する。

- `html/lesson.html`
- `js/lesson.js`
- `css/lesson.css`
- `json/lessons/lesson-index.json`
- `json/lessons/<unit>/*.json`

URL: `html/lesson.html?id=<LESSON_ID>`

基本フィールド:

- `meta.id`
- `meta.title`
- `meta.unitId`
- `meta.officialMiddleCodes`
- `meta.qualityStatus`
- `meta.replacesTemplateFor[]`
- `objectives[]`
- `sections[]`
- `checks[]`
- `next[]`

対応section type:

- `text`
- `comparison`
- `diagram`
- `code-trace`
- `steps`
- `mistakes`

Lessonナビは同じ `unitId` 内をorder順で前後移動し、別ユニットへの移動は `next[]` で明示する。
