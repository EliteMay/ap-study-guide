# AP Study Guide 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の学習用静的Webアプリ。

- Repository: `EliteMay/ap-study-guide`
- Public: `https://elitemay.github.io/ap-study-guide/`
- 正式要件のSource of Truth: Repository Root `REQUIREMENTS.md`
- Build / Project Profile正本: `json/project-meta.json`
- 制作Guide: `EliteMay/web-project-guide`
- Project Memory: `PROJECT_LEARNINGS.md`
- 基準: IPA 応用情報技術者試験 シラバス Ver.7.2
- 技術: HTML / CSS / JavaScript / JSON
- Deployment: GitHub Pages

Project Profile: `STATIC + DATA + LEARNING + TOOL + PUBLIC-CONTENT`

## 2. Product Goal

初学者が単語だけを暗記するのではなく、仕組み・理由・具体例まで理解し、問題演習と復習へつなげてAP合格水準へ近づけること。

基本導線:

**Home → Lesson → 途中確認 → 末尾確認 → 関連短問 → Case / Mock → 公開公式問題 → 弱点復習**

分からない内容は横断検索からLesson・用語・問題へ戻る。

## 8. Lesson

### 8.1 既存保存Contract

- Progress Key: `ap-study-lesson-progress-v1`

- 75%以上で現行の「理解確認済み」
- 現行Runtimeでは14日後に再確認対象

Phase 2導入まで、このKeyと判定を名称変更だけの理由で変更しない。

### 8.2 Phase 1 Lesson Contract

Phase 1対象Lessonは原則として次を持つ。

- importance
- frequency
- examFocus
- prerequisiteLessons
- relatedLessons
- relatedTerms
- relatedPracticeRefs
- officialProblemRefs
- 学習目標
- 十分な本文Section
- 必要な図解 / 比較 / Trace
- よくある誤解
- inlineChecks
- 末尾確認問題

Phase 1 Metadataは、既存Lesson JSONの`meta`へ直接持たせてもよいし、既存本文を大量書換えしない方が安全な場合は `json/phase1/index.json` から該当Unitの補助JSONを遅延読込してOverlayしてよい。

`inlineChecks` は学習途中の理解確認で、現行の学習進捗には保存しない。保存対象の理解判定は末尾確認問題が担当する。

## 14. Shared Shell / Navigation

Runtime: `js/shell.js`

Group:

- 学習: Home / 学習分野 / Progress
- 調べる: 横断検索 / 単語辞書 / 公式問題
- 演習: Practice / Case / Mock

Desktop Sidebar / Mobile Drawerを共通化する。

Unit HubはCurriculum Dataから現在Unit数を取得してBreadcrumbを描画し、Product titleは`AP Study Guide`を使用する。1 Lessonが複数IPA中分類に属する場合は複数Groupへ表示されるため、画面上のCard数とUnique Lesson数は同一とは限らない。

UI・情報メディアではLesson Indexの`order`を学習順の正本とし、Unit Hub表示番号もそのUnit内の順序から算出する。r29では `UIM-01〜04 → MED-01〜04` を維持する。
