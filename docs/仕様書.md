# AP Study Notes 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の個人学習用静的Webアプリ。

- 正本: GitHub `EliteMay/ap-study-notes`
- 主利用環境: GitHub Pages
- Build / Project Profile正本: `json/project-meta.json`
- 制作Guide: `EliteMay/web-project-guide`
- Guide採用Version: `json/project-meta.json` に記録
- 基準: IPA 応用情報技術者試験 シラバス Ver.7.2
- 技術: HTML / CSS / JavaScript / JSON / PDF
- Server必須機能・秘密情報なし

Project Profile:

`STATIC + DATA + TOOL + PUBLIC-CONTENT`

## 2. 目的

1. Homeから目的をすぐ選べる。
2. 13Unitから体系的に学ぶ。
3. 構造化Lessonで仕組みを理解する。
4. 短問・長文Case・模試で取り出す。
5. 最新公開公式問題へ接続する。
6. 分からない用語は統合辞書で即時検索する。
7. 進捗Dashboardから弱点へ戻る。
8. 学習データを安全にBackup / Restoreできる。

優先順位: **操作性 → 分かりやすさ → 安定性 → 軽量性 → 保守性 → 見た目**。

## 3. Source of Truth

`json/project-meta.json`

## 4. Home

Page: `index.html`  
Runtime: `js/home.js`  
Style: `css/home.css` + `css/home-launch.css`

Homeの第一責務は「行動選択」。詳細Dashboardではない。

主要Action:

- Lesson
- 単語辞書
- 短問
- 長文Case
- 150分模試
- 公式公開問題
- 学習進捗
- 学習データ

`#home-quick-search` は機能名・13Unit名を候補表示し、候補にない語も `html/glossary.html?q=<QUERY>` へ送る。

教材件数はLoader成功後にDataから表示する。初期HTMLは固定件数を持たない。

### 4.1 Home状態

- Loading: 初期表示
- Success: 進捗・Unitを表示
- Empty: Unit Dataが空なら説明を表示
- Error: Loader失敗時に「教材データを読み込めませんでした」と再読込導線を表示

Loader失敗時も主要8Action Cardは利用可能とする。

FinderのEvent Listenerは初回だけbindし、学習状態再集計で重複登録しない。

### 5.1 対象

### 5.2 機能

- `html/database.html`

## 14. Backup / Restore

Page: `html/data.html`  
Runtime: `js/data-tools.js`

### 14.1 Export

`APStudyState.recognizedKeys()` の認識済みlocalStorageのみを書き出す。

Backup Schema Versionは `json/project-meta.json` の `storage.backupSchemaVersion` を正本とする。

### 14.2 Import Validation

順序:

1. JSON parse
2. App確認
3. Backup Schema Version確認
4. `storage` object確認
5. 認識済みKey抽出
6. Keyごとの保存形式確認
7. Preview
8. User confirm
9. 現在データの復元前Backup Download
10. commit

Keyごとの最低形式:

- Theme: `light` / `dark`
- Lesson / Practice / Case / Active Mock: JSON object
- Mock History / Bookmark / Recent / Legacy Test / Legacy checked: JSON array

壊れた認識済みJSONが1つでも含まれる場合はRestoreを有効化しない。

### 14.3 Safe Preview

Import JSON由来の `build` / `exportedAt` 等をraw `innerHTML`へ入れない。DOM Node + `textContent` でPreviewする。

### 14.4 Commit / Rollback

Restore開始前に上書き対象の現在値をMemoryへ退避する。

`localStorage.setItem` が途中で失敗した場合は、退避した値を使って可能な範囲でRollbackする。

現在保存データが存在する場合、Restore直前のBackup JSONを自動Downloadする。

## 15. Shared Shell

`js/shell.js`

Navigation:

- 学習: Home / 13Unit / Progress
- 調べる: Glossary / Official Public Questions
- 演習: Short / Long Case / Mock
- 管理・互換: Security Past / Data / Legacy Term Test

Build表示は `project-meta.json` を非同期読込して反映する。Metadata読込失敗時もNavigation自体は利用可能とする。

Mobile Drawer:

- Closed: `inert` + `aria-hidden`
- Escape: close + focus return
- Skip Link
- `focus-visible`
- `prefers-reduced-motion`

## 16. Data保存

教材: GitHub JSON  
個人履歴: Browser localStorage

Key正本: `js/study-state.js`

保存Key / Schemaを変更するときはMigrationを用意し、旧データを先に破壊しない。

## 17. GitHub Pages

- 相対Pathを維持する
- `fetch()`先をサブパス対応にする
- `localhost` / PC固有絶対Pathへ依存しない
- 公開ArtifactへSecretを入れない
- 正式利用はGitHub PagesまたはHTTP Server経由

- Source of Truth
- Project Profile / Guide Version

- Glossary

## 19. 崩してはいけない仕様

- 既存Term IDを変更・再利用・削除しない。
- 既存localStorage Keyを変更する場合はMigrationを用意する。
- Legacy用語ページを互換層として維持する。
- 通常用語検索入口はGlossaryへ統一する。
- Runtime正本Manifestを分岐させない。
- Buildを複数Runtimeへ手入力しない。
- Import前Validationを外さない。
- Restoreで元データを先に破壊しない。
- 13Unit通常入口はGeneric Unit Hubへ統一する。
- GitHub Pages相対Pathを維持する。
- Secretを公開Repoへ入れない。
- 2026非公開実問題を公開問題として扱わない。
