# AP Study Notes 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の個人学習用静的Webアプリ。

- 正本: GitHub `EliteMay/ap-study-notes`
- 主利用環境: GitHub Pages
- 構成: HTML / CSS / JavaScript / JSON / PDF
- BUILD: `2026.08.29-r5`
- 状態: **機能基盤は利用可能 / 教材内容は再設計中**

ページ数・用語数・動作だけでは教材完成としない。

## 2. 要件定義

### 目的

AP合格に必要な知識を、単語暗記ではなく、計算・図・コード・SQL・ケース問題まで含めて理解し、問題へ適用できるようにする。

### 利用者

個人学習者。優先順位は操作性、分かりやすさ、軽量性、保守性、見た目。

### 必要機能

- AP全範囲の学習マップ
- 学習項目に適した教材形式
- 検索 / 復習 / 進捗
- 内容別演習
- 過去問
- 解答履歴
- 理解度可視化
- GitHub Pagesでの静的利用

### 保存

- 教材: GitHub上のJSON
- 個人進捗: localStorage

### 崩してはいけない仕様

- 既存用語IDと進捗対応を不用意に壊さない。
- localStorageキー変更時は移行処理を用意する。
- 過去問PDF / 問題JSON / 解説JSONの対応を壊さない。
- GitHub Pagesの相対パスを壊さない。
- 秘密情報/APIキーを公開リポジトリへ置かない。
- 監査前の大量削除・大量ID変更をしない。

### 教材完成条件

- 対象シラバス全範囲を追跡できる。
- テンプレ文章による水増しがない。
- 各内容に適した教材形式がある。
- 必要な計算 / 図 / コード / SQL / ケース演習がある。
- 最近の過去問へ接続できる。
- 問題結果から理解度を確認できる。
- CIとPages buildが通る。

## 6. 構造化Lesson

用語カードだけでは扱えない内容の主教材。

- HTML: `html/lesson.html`
- JS: `js/lesson.js`
- CSS: `css/lesson.css`
- Index: `json/lessons/lesson-index.json`
- Data: `json/lessons/<unit>/*.json`

URL:

`html/lesson.html?id=<LESSON_ID>`

indexに登録されたIDだけを読み込む。

基本フィールド:

- `meta.id`
- `meta.title`
- `meta.unitId`
- `meta.officialMiddleCodes`
- `meta.qualityStatus`
- `meta.replacesTemplateFor[]`
- `objectives[]`
- `sections[]`
- `checks[]`
- `next[]`

現在対応するsection type:

- `text`
- `comparison`
- `diagram`
- `code-trace`
- `steps`
- `mistakes`

### diagram

JSONの構造情報を軽量なHTML図として描画する。

用途:

- 配列
- 連結リスト
- 木
- グラフ
- 将来のER/UML/ネットワーク構成

基本形:

```json
{
  "type": "diagram",
  "title": "...",
  "diagrams": [
    {
      "label": "...",
      "connector": "→",
      "nodes": [
        {"title":"Node A","value":"10","meta":"next=B"}
      ],
      "note": "..."
    }
  ]
}
```

図は横方向に収まらない場合、内部だけ横スクロールさせる。

- コードからオーダを読む手順
- 確認問題

- 配列と単方向連結リストの構造図
- 添字アクセス / 探索 / 挿入 / 削除の計算量比較
- 配列途中挿入の要素移動
- 連結リストの参照変更
- 「挿入O(1)」が成立する条件
- 動的配列 / 多次元配列
