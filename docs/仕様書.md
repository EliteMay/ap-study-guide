# AP Study Notes 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の個人学習用静的Webアプリ。

- 正本: GitHub `EliteMay/ap-study-notes`
- 主利用環境: GitHub Pages
- 構成: HTML / CSS / JavaScript / JSON / PDF
- BUILD: `2026.08.29-r5`
- 状態: **機能基盤は利用可能 / 教材内容は再設計中**

ページ数・用語数・動作だけでは教材完成としない。

## 2. 目的と優先順位

目的:

AP合格に必要な知識を、単語暗記だけでなく計算・図・コード・SQL・ケース問題まで含めて理解し、問題へ適用できるようにする。

優先順位:

1. 操作性
2. 分かりやすさ
3. 軽量性
4. 保守性
5. 見た目

教材はGitHub上のJSON、個人進捗はlocalStorageへ保存する。

## 3. 崩してはいけない仕様

- 既存用語IDと進捗対応を不用意に壊さない。
- localStorageキー変更時は移行処理を用意する。
- 過去問PDF / 問題JSON / 解説JSONの対応を壊さない。
- GitHub Pagesの相対パスを壊さない。
- 秘密情報/APIキーを公開リポジトリへ置かない。
- 監査前の大量削除・大量ID変更をしない。

## 7. 構造化Lesson

用語カードだけでは扱えない内容の主教材。

構成:

- `html/lesson.html`
- `js/lesson.js`
- `css/lesson.css`
- `json/lessons/lesson-index.json`
- `json/lessons/<unit>/*.json`

URL:

`html/lesson.html?id=<LESSON_ID>`

基本フィールド:

- `meta.id`
- `meta.title`
- `meta.unitId`
- `meta.officialMiddleCodes`
- `meta.qualityStatus`
- `meta.replacesTemplateFor[]`
- `objectives[]`
- `sections[]`
- `checks[]`
- `next[]`

現在対応するsection type:

- `text`
- `comparison`
- `diagram`
- `code-trace`
- `steps`
- `mistakes`

Lessonナビ:

- 同じ `unitId` 内では `order` 順で自動前後移動。
- 別ユニットへ進む場合は `next[]` で明示する。

## 9. 旧アルゴリズム65語の完全移行ルール

- 未割当禁止。
