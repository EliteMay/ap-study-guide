# AP Study Notes 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の個人学習用静的Webアプリ。

- 正本: GitHub `EliteMay/ap-study-notes`
- 主利用環境: GitHub Pages
- BUILD: `2026.08.30-r10`
- 基準: IPA 応用情報技術者試験 シラバス Ver.7.2
- 技術: HTML / CSS / JavaScript / JSON / PDF
- Server必須機能・秘密情報なし

現在は **旧教材監査完了 / 23中分類すべてにLessonあり / 総合演習を増強中** の段階。

## 2. 目的

APの知識を単語暗記で終わらせず、次のFlowで定着させる。

1. 範囲を把握
2. 構造化Lessonで理解
3. Lesson内確認問題
4. 分野横断のオリジナル総合演習
5. 弱点再学習
6. 公式過去問・Subject B長文へ接続

優先順位:

1. 操作性
2. 分かりやすさ
3. 軽量性
4. 保守性
5. 見た目

## 3. 崩してはいけない仕様

- 既存用語IDを不用意に削除・変更しない。
- 旧用語進捗localStorageを維持する。
- localStorage keyを変更するときは移行処理を用意する。
- 過去問PDF / 問題JSON / 解説JSONの対応を壊さない。
- GitHub Pagesで壊れない相対Pathを維持する。
- API Key / Password等を公開Repoへ置かない。
- 監査済みIDの主Lesson割当を根拠なく変えない。
- `lesson-index.json` と `lesson-index-expansion.json` をRuntime / CI双方で結合する。
- 「全23中分類にLessonあり」を「試験対策として完成」と誤表現しない。

## 6. 構造化Lesson Architecture

### 6.1 Runtime

- `html/lesson.html`
- `js/lesson.js`
- `css/lesson.css`

URL:

`html/lesson.html?id=<LESSON_ID>`

### 6.2 Index

- `json/lessons/lesson-index.json` — Base 87
- `json/lessons/lesson-index-expansion.json` — Expansion 31
- Total **118 Lesson**

巨大Indexを1ファイルへ増やし続けず、既存安定群と追加群を分離する。

### 6.3 Lesson JSON

主なmeta:

- `id`
- `title`
- `unitId`
- `officialMiddleCodes[]`
- `qualityStatus`
- `estimatedMinutes`
- 必要時 `legacySources[]`
- 必要時 `legacyTermIds[]`
- 必要時 `legacyTermRanges[]`

本文:

- `intro`
- `objectives[]`
- `sections[]`
- `checks[]`
- 必要時 `next[]`

section type:

- `text`
- `comparison`
- `diagram`
- `code-trace`
- `worked-example`
- `steps`
- `mistakes`

### 6.4 Lesson Navigation

- 同一 `unitId` の `order` 順で前後移動。
- `next[]` がある場合は明示Linkを優先。
- 関連Practiceが存在する場合、Lesson下部から該当問題へ直接移動。

- difficulty

- `status`
