# AP Study Notes 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の個人学習用静的Webアプリ。

- 正本: GitHub `EliteMay/ap-study-notes`
- 主利用環境: GitHub Pages
- 構成: HTML / CSS / JavaScript / JSON / PDF
- BUILD: `2026.08.29-r5`
- 状態: **機能基盤は利用可能 / 教材内容は再設計中**

「ページ数」「用語数」「動作すること」だけでは教材完成としない。

## 2. 要件定義

### 目的

AP合格に必要な知識を、単語暗記ではなく、計算・図・コード・SQL・ケース問題まで含めて理解し、問題へ適用できるようにする。

### 利用者

個人学習者。軽量性・操作性・分かりやすさ・学習効率を優先する。

### 必要機能

- AP全範囲の学習マップ
- 学習項目に適した教材形式
- 検索 / 復習 / 進捗
- 内容別演習
- 過去問
- 解答履歴
- 理解度可視化
- GitHub Pagesでの静的利用

### 保存

- 教材: GitHub上のJSON
- 個人進捗: localStorage

### 崩してはいけない仕様

- 既存用語IDと進捗対応を不用意に壊さない
- localStorageキー変更時は移行を用意する
- 過去問PDF / 問題文 / 解説の対応を壊さない
- GitHub Pagesの相対パスを壊さない
- 秘密情報/APIキーを公開リポジトリへ置かない

### 教材完成条件

- 対象シラバス全範囲を追跡できる
- テンプレ文章による水増しがない
- 各内容に適した教材形式がある
- 必要な計算 / 図 / コード / SQL / ケース演習がある
- 最近の過去問へ接続できる
- 問題結果から理解度を確認できる
- CIとPages buildが通る

## 6. 教材形式

### concept

用語・概念・比較。短い定義、仕組み、比較、誤解、APでの使われ方を扱う。

### calculation

EVM、PERT、サブネット、待ち行列、性能等。公式、変数、途中式、例題、類題を持つ。

### code-trace

擬似言語・アルゴリズム。コード、初期値、各行実行後の状態、最終結果を持つ。

### structured-operation

SQL・正規化。入力表、操作、中間状態、結果を持つ。

### diagram

ER図、UML、ネットワーク図。図、見る順番、記号、根拠、誤読例を持つ。

### case

セキュリティ、PM、サービス、戦略、法務等。状況、条件、根拠、回答、解説を持つ。

## 8. 構造化Lesson

用語カードだけでは扱えない内容の主教材。

構成:

- HTML: `html/lesson.html`
- JS: `js/lesson.js`
- CSS: `css/lesson.css`
- Index: `json/lessons/lesson-index.json`
- Data: `json/lessons/<unit>/*.json`

URL:

`html/lesson.html?id=<LESSON_ID>`

indexに登録されたIDだけを読み込む。

Lessonの基本フィールド:

- `meta.id`
- `meta.title`
- `meta.unitId`
- `meta.officialMiddleCodes`
- `meta.qualityStatus`
- `objectives[]`
- `sections[]`
- `checks[]`
- `next[]`

現在対応するsection type:

- `text`
- `comparison`
- `code-trace`
- `steps`
- `mistakes`

必要になった時点で `calculation` / `diagram` / `structured-operation` / `case` 等をrendererへ追加する。

### ALG-01

最初の個別Lesson:

`ALG-01 アルゴリズムの表現と擬似言語トレース`

Data:

`json/lessons/algorithm/alg-01-pseudocode-trace.json`

置換対象:

- `term-alg-001`
- `term-alg-002`
- `term-alg-003`

内容:

- 入力 / 処理 / 出力
- 代入 / 条件分岐 / 繰返し / 配列参照
- 分岐トレース
- 配列+ループトレース
- 5段階の実践トレース手順
- 典型的失点
- 確認問題

`qualityStatus: individual-v1` は、共通生成文章ではなく教材固有に構成した初版を意味する。
