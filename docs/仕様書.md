# AP Study Notes 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の個人学習用静的Webアプリ。

- 正本: GitHub `EliteMay/ap-study-notes`
- 主利用環境: GitHub Pages
- 構成: HTML / CSS / JavaScript / JSON / PDF
- BUILD: `2026.08.29-r5`
- 状態: **機能基盤は利用可能 / 教材内容は再設計中**

用語数やページ数だけでは教材完成としない。

## 2. 目的・優先順位

目的はAP合格に必要な知識を、単語暗記だけでなく計算・図・コード・SQL・ケースへ適用できる状態にすること。

優先順位:

1. 操作性
2. 分かりやすさ
3. 軽量性
4. 保守性
5. 見た目

## 3. 崩してはいけない仕様

- 既存用語IDと進捗対応を不用意に壊さない。
- localStorageキー変更時は移行処理を用意する。
- 過去問PDF / 問題JSON / 解説JSONの対応を壊さない。
- GitHub Pagesの相対パスを壊さない。
- 秘密情報/APIキーを公開リポジトリへ置かない。
- 監査前の大量削除・大量ID変更をしない。
- 未確認事項を確認済みとして扱わない。

## 6. 監査action

監査JSONで使用する基本action:

- `keep-core`: Lessonの主要項目として残す。
- `keep-supporting`: 比較・補足・演習で扱う。
- `merge-into-lesson`: 単独カードにせず上位Lessonへ統合する。
- `move-primary-unit`: 主教材を別学習ユニットへ移す。

監査ファイル:

- `json/curriculum/audits/algorithm-audit.json`
- `json/curriculum/audits/system-audit.json`
- `json/curriculum/audits/management-audit.json`

## 7. 構造化Lesson基盤

共通画面:

`html/lesson.html?id=<LESSON_ID>`

構成:

- `html/lesson.html`
- `js/lesson.js`
- `css/lesson.css`
- `json/lessons/lesson-index.json`
- `json/lessons/<unit>/*.json`

基本フィールド:

- `meta.id`
- `meta.title`
- `meta.unitId`
- `meta.officialMiddleCodes`
- `meta.qualityStatus`
- `meta.replacesTemplateFor[]`（旧Algorithm移行）
- `meta.legacyTermIds[]`（System/Management等の旧用語移行）
- `objectives[]`
- `sections[]`
- `checks[]`
- `next[]`

section type:

- `text`
- `comparison`
- `diagram`
- `code-trace`
- `steps`
- `mistakes`

Lessonナビ:

- 同じ`unitId`内は`order`順で自動前後移動。
- 別ユニットへの遷移は`next[]`で明示する。
