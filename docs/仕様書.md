# AP Study Notes 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の個人学習用静的Webアプリ。

- 正本: GitHub `EliteMay/ap-study-notes`
- 主利用環境: GitHub Pages
- BUILD: `2026.08.30-r12`
- 基準: IPA 応用情報技術者試験 シラバス Ver.7.2
- 技術: HTML / CSS / JavaScript / JSON / PDF
- Server/API Key不要

現在は **旧教材1,422語監査完了 / 118Lesson / 短問91問 / 長文6Case・18設問 / 23中分類すべてにLesson+短問あり** の段階。

## 2. 学習Flow

1. 学習マップで範囲確認
2. 構造化Lessonで理解
3. Lesson内確認問題
4. 短問総合演習で適用
5. 長文Caseで複数情報を統合
6. 進捗Dashboardで弱点確認
7. 公式過去問へ接続

## 3. 崩してはいけない仕様

- 既存用語IDを不用意に削除・変更しない。
- localStorage key変更時はMigrationを用意する。
- 過去問PDF / 問題JSON / 解説JSON対応を壊さない。
- GitHub Pagesで動く相対Pathを維持する。
- 秘密情報を公開Repoへ置かない。
- 監査済みIDの主Lesson割当を根拠なく変えない。
- Base/Expansion Lesson indexをRuntime/CIで結合する。
- Practice Runtimeは `practice-index.json` を正本とする。
- 旧37問Practice SnapshotへRuntimeを戻さない。
- 23/23 Coverageと試験対策の完成を混同しない。
