# AP Study Notes 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の個人学習用静的Webアプリ。

- 正本: GitHub `EliteMay/ap-study-notes`
- 主利用環境: GitHub Pages
- BUILD: `2026.08.30-r11`
- 基準: IPA 応用情報技術者試験 シラバス Ver.7.2
- 技術: HTML / CSS / JavaScript / JSON / PDF
- Server/API Key不要

現在は **旧教材1,422語監査完了 / 118Lesson / 総合演習91問 / 23中分類すべてにLesson+Practiceあり** の段階。

## 2. 目的

学習Flow:

1. 学習マップで範囲確認
2. 構造化Lessonで理解
3. Lesson内確認問題
4. 総合演習で適用
5. 進捗Dashboardで弱点確認
6. 要復習を再挑戦
7. 公式過去問・Subject B長文へ接続

優先順位:

1. 操作性
2. 分かりやすさ
3. 軽量性
4. 保守性
5. 見た目

## 3. 崩してはいけない仕様

- 既存用語IDを不用意に削除・変更しない。
- 旧用語進捗localStorageを維持する。
- localStorage key変更時は移行処理を用意する。
- 過去問PDF / 問題JSON / 解説JSON対応を壊さない。
- GitHub Pagesで動く相対Pathを維持する。
- API Key / Passwordを公開Repoへ置かない。
- 監査済みIDの主Lesson割当を根拠なく変更しない。
- `lesson-index.json` + `lesson-index-expansion.json` をRuntime/CIで結合する。
- Practice Runtimeは `json/practice/practice-index.json` を正本とする。
- 旧37問Bank `ap-original-practice-v1.json` はSnapshotとして維持し、Runtimeへ戻さない。
- 23/23 Coverageと試験対策の完全性を混同しない。
