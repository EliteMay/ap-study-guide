# AP Study Notes 仕様書

## 1. 概要

応用情報技術者試験（AP）の学習用静的Webサイトです。

GitHubリポジトリ `EliteMay/ap-study-notes` を正本とし、HTML/CSS/JavaScript/JSON/PDFで構成します。現在の構成は固定ではなく、学習効果・操作性・軽量性・保守性が上がるなら再設計して構いません。

## 3. 共通用語ページ

`security.html`、`network.html`、`database.html` は共通エンジンを利用します。

### 共通実装

- `js/term-page.js`
- `css/term-page.css`

### ページ固有設定

各HTMLは `window.TERM_PAGE_CONFIG` で以下を指定します。

- 表示名
- 用語マニフェスト
- 詳細解説マニフェスト
- localStorageキー
- フォールバックID接頭辞
- ルート相対パス

### 共通機能

- マニフェスト読み込み
- カテゴリ別JSON読み込み
- 用語一覧生成
- カテゴリ目次生成
- リアルタイム検索
- カテゴリフィルタ
- 詳細解説の遅延描画
- 用語間自動リンク
- URLハッシュから用語カードを開く
- 習得済みチェック
- 進捗バー
- localStorage保存
- 無効になった古い進捗IDの整理
- 目次ハイライト
- 基本データ整合警告

## 4. 用語データ

### 軽量用語

保存先: `json/terms/`

```json
{
  "id": "...",
  "term": "...",
  "aliases": [],
  "category": "...",
  "definition": "..."
}
```

### 詳細解説

保存先: `json/details/`

主なフィールド:

- `id`
- `term`
- `category`
- `level`
- `tags`
- `beginner`
- `example`
- `examPoint`
- `trap`
- `deepDive`
- `relatedConcepts`
- `commonMistakes`
- `afternoonUse`
- `howToRemember`

用語JSONと `id`、`term`、`category` を対応させます。

## 6. ホーム

### ファイル

- `index.html`
- `css/home.css`
- `js/home.js`

### 仕様

- 学習単元カード数をDOMから集計する。
- 公開中単元数をDOM状態から集計する。
- 3分野の総語数は各マニフェストから取得する。
- 習得済み数は各localStorageキーから取得する。
- 過去問数は `security-past-index.json` から取得する。
- テストと過去問は「演習・復習」として学習単元カードから分けて表示する。

## 8. セキュリティ過去問

### 保存場所

- 索引: `security-past-index.json`
- 問題文: `json/past-problems/`
- 解説: `json/past/`
- PDF: `sources/`

### 対応ルール

索引側:

- `file`
- `problemFile`
- `sourcePdf`

解説側:

- `sourceProblemFile`
- `sourcePdf`
- `sections`

問題文側:

- `problem.questions[].label`
- `problem.questions[].targets`

解説 `sections[].answerTargets` と問題文 `questions[].targets` は、同じ設問ラベル同士で一致させます。

## 9. テスト

### 現行版

- `html/test.html`
- `css/test.css`
- `js/test.js`

正式な軽量用語JSONを直接読み込み、その場で4択問題を生成します。

### 読み込み元

- `security-terms-manifest.json`
- `network-terms-manifest.json`
- `database-terms-manifest.json`
- 各 `json/terms/*.json`

詳細解説JSONは通常テストでは読み込みません。問題生成に必要な短い定義だけを使い、初期読み込みを抑えます。

### 現在の機能

- 3分野ミックス
- 分野指定
- 問題数指定（最大100）
- 説明→用語
- 用語→説明
- ミックス
- 同カテゴリ中心の選択肢
- 説明文内の正解語/別名を自動マスク
- 1〜4キーで回答
- Enterで次へ
- 結果表示
- 間違えた問題一覧
- 間違えた問題だけ再テスト
- 用語ページへの復習リンク

### 旧版

`html/test-legacy.html`

旧テストにあった手作りAP本番風問題を失わないため、一時保存しています。通常ナビゲーションからは新テストを使います。

将来的には手作り問題だけを `json/test/` などへ抽出し、本番風モードとして新テストへ統合した後、legacyページを削除できます。

## 10. 品質チェック

`tools/check-json.html`

### 用語系

- 3分野すべてを検査
- ファイルごとのcount
- manifest総数
- 用語ID重複
- term重複
- 詳細ID重複
- 用語/詳細のID対応
- term一致
- category一致

### 過去問

- 索引の解説ファイル読み込み
- `problemFile` 読み込み
- `sourceProblemFile` 対応
- `sourcePdf` パス情報対応
- `sections`
- `answerTargets`
- `expectedAnswers`
- 問題文 `targets` と解説 `answerTargets` の一致
- 問題文側の設問に解説漏れがないか

基本完了条件は `ERROR 0` です。
