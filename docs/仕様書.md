# AP Study Notes 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の個人学習用静的Webアプリ。

- 正本: GitHub `EliteMay/ap-study-notes`
- 主利用環境: GitHub Pages
- BUILD: `2026.08.30-r13`
- 基準: IPA 応用情報技術者試験 シラバス Ver.7.2
- 技術: HTML / CSS / JavaScript / JSON / PDF
- Server必須機能・秘密情報なし

現在は **旧教材1,422語監査完了 / 118Lesson / 短問91問 / 長文Case14本42設問 / 13Unit・23中分類すべてに学習・演習入口あり** の段階。

## 2. 目的

APの知識を単語暗記で終わらせず、次のFlowで定着させる。

1. 範囲把握
2. 構造化Lessonで理解
3. Lesson内確認問題
4. 短問総合演習
5. 長文Case演習
6. 弱点再学習
7. 公式過去問へ接続

優先順位:

1. 操作性
2. 分かりやすさ
3. 軽量性
4. 保守性
5. 見た目

## 3. 崩してはいけない仕様

- 既存用語IDを不用意に削除・変更しない。
- 旧用語進捗localStorageを維持する。
- localStorage Key変更時は移行処理を用意する。
- 過去問PDF / 問題JSON / 解説JSONの対応を壊さない。
- GitHub Pagesで壊れない相対Pathを維持する。
- API Key / Password等を公開Repoへ置かない。
- 監査済みIDの主Lesson割当を根拠なく変えない。
- LessonはBase / Expansion indexをRuntime / CI双方で結合する。
- Practiceは`json/practice/practice-index.json`をRuntime正本とする。
- Caseは`json/cases/case-index.json`をRuntime正本とする。
- 「全23中分類に教材あり」を「試験対策として完全」と誤表現しない。
