# AP Study Notes 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の個人学習用静的Webアプリ。

- 正本: `EliteMay/ap-study-notes`
- 利用環境: GitHub Pages
- BUILD: **`2026.08.30-r16`**
- 基準: IPA 応用情報技術者試験 シラバス Ver.7.2
- 技術: HTML / CSS / JavaScript / JSON / PDF

現在は **旧1,422語監査完了 / 118Lesson / 91短問 / 16Case48設問 / 科目A・B模試 / 2025春秋公開午後22大問Mapping** の状態。

## 2. 目的

1. 13学習ユニットから範囲を把握する。
2. 構造化Lessonで仕組みを理解する。
3. 直後確認で理解度を測る。
4. 短問・長文Caseで取り出し練習する。
5. 150分模試で時間配分を練習する。
6. 公開公式問題へ接続する。
7. 現在の理解状態と復習期限から弱点へ戻る。
8. 学習データをBackup / Restoreできる。

## 3. 崩してはいけない仕様

- 既存用語IDとlocalStorage Keyを不用意に変更しない。
- 既存過去問PDF / 問題JSON / 解説JSONの対応を壊さない。
- GitHub Pagesの相対Pathを維持する。
- 秘密情報を公開Repoへ置かない。
- Practiceは`practice-index.json`、Caseは`case-index.json`をRuntime正本とする。
- Lessonは`js/lesson-data.js`を通してBase87 + Expansion31を結合する。
- 習得判定は`js/study-state.js`を正本とする。
- 13Unitの通常学習入口は`unit.html?unit=<id>`に統一する。
- 旧6巨大Hubは削除せず旧用語辞書・互換層として維持する。
- 2026 CBT実問題を公開過去問・再現問題として扱わない。
- 模試結果をIPA公式得点へ直接換算しない。
- `23/23 Coverage`を試験対策の完全性と表現しない。

## 5. Lesson

- Page: `html/lesson.html?id=<LESSON_ID>`
- Base index: `json/lessons/lesson-index.json` — 87
- Expansion index: `json/lessons/lesson-index-expansion.json` — 31
- Loader: `js/lesson-data.js`
- Total: **118**

### Lesson理解判定

- 全確認問題へ回答する。
- 正答率 **75%以上**を理解確認基準とする。
- Bestは履歴として保持するが、現在状態は最新結果と更新日時から判定する。
- 14日経過した理解済みLessonは復習期限扱いにできる。

履歴: `ap-study-lesson-progress-v1`

## 6. 短問

- Page: `html/practice.html`
- Manifest: `json/practice/practice-index.json`
- Loader: `js/practice-data.js`
- 91問 = Choice57 + Written34
- 13/13 Unit、23/23中分類

### 短問理解判定

- Choice: 最新正解かつ最近の結果を重視。
- Written: 12文字以上回答後のみModel Answerを開ける。
- Writtenの現在理解は最新自己評価2点を基準にする。
- 14日経過した理解済み問題は復習期限扱い。

履歴: `ap-study-practice-history-v1`

## 7. 長文Case

- Page: `html/cases.html`
- Manifest: `json/cases/case-index.json`
- Loader: `js/case-data.js`
- 16Case / 48 Written
- 13/13 Unit、23/23中分類

通常Caseでは20文字以上の回答がない限りModel Answerを開けない。

履歴: `ap-study-case-history-v1`

## 8. 模試

Page: `html/mock.html`

### 科目A

- 80問 / 80解答 / 150分

### 科目B

- 11問提示 / 5問解答 / 150分

- 提出後自己採点

設定正本: `json/mock/mock-config.json`

## 9. 公式公開問題

- 2026年度APはCBT。
- 2026 CBTの実問題は非公開。
- 最新公開済みフル問題として2025春・秋を使用。
- `json/past/ap-public-exams.json`で午後22大問をLessonへMapping。
- 問題全文は転載せずIPA公式PDFへLinkする。

## 11. Home / Navigation

Homeは以下の3層。

1. 今日やること
2. 13Unit
3. 演習・本番・管理

Shared Navigationは以下へ整理。

- 学習: Home / 13Unit / Progress
- 演習: Practice / Case / Mock
- 本番・管理: Official Past / Security Past / Data / Legacy Test

Mobile Drawer:

- 閉時 `inert`
- `aria-hidden`
- 開時NavigationへFocus
- EscapeでClose
- Menu buttonへFocus Restore
- Skip Linkあり
