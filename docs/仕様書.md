# AP Study Notes 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の個人学習用静的Webアプリ。

- 正本: GitHub `EliteMay/ap-study-notes`
- 主利用環境: GitHub Pages
- 構成: HTML / CSS / JavaScript / JSON / PDF
- BUILD: `2026.08.29-r5`
- 状態: **機能基盤は利用可能 / 教材内容は再設計中**

ページ数・用語数・動作だけでは教材完成としない。

## 2. 要件定義

### 目的

AP合格に必要な知識を、単語暗記ではなく、計算・図・コード・SQL・ケース問題まで含めて理解し、問題へ適用できるようにする。

### 利用者

個人学習者。優先順位は操作性、分かりやすさ、軽量性、保守性、見た目。

### 必要機能

- AP全範囲の学習マップ
- 学習項目に適した教材形式
- 検索 / 復習 / 進捗
- 内容別演習
- 過去問
- 解答履歴
- 理解度可視化
- GitHub Pagesでの静的利用

### 保存

- 教材: GitHub上のJSON
- 個人進捗: localStorage

### 崩してはいけない仕様

- 既存用語IDと進捗対応を不用意に壊さない。
- localStorageキー変更時は移行処理を用意する。
- 過去問PDF / 問題JSON / 解説JSONの対応を壊さない。
- GitHub Pagesの相対パスを壊さない。
- 秘密情報/APIキーを公開リポジトリへ置かない。
- 監査前の大量削除・大量ID変更をしない。

### 教材完成条件

- 対象シラバス全範囲を追跡できる。
- テンプレ文章による水増しがない。
- 各内容に適した教材形式がある。
- 必要な計算 / 図 / コード / SQL / ケース演習がある。
- 最近の過去問へ接続できる。
- 問題結果から理解度を確認できる。
- CIとPages buildが通る。

## 6. 構造化Lesson

用語カードだけでは扱えない内容の主教材。

- HTML: `html/lesson.html`
- JS: `js/lesson.js`
- CSS: `css/lesson.css`
- Index: `json/lessons/lesson-index.json`
- Data: `json/lessons/<unit>/*.json`

URL: `html/lesson.html?id=<LESSON_ID>`

indexに登録されたIDだけを読み込む。

基本フィールド:

- `meta.id`
- `meta.title`
- `meta.unitId`
- `meta.officialMiddleCodes`
- `meta.qualityStatus`
- `meta.replacesTemplateFor[]`
- `objectives[]`
- `sections[]`
- `checks[]`
- `next[]`

現在対応するsection type:

- `text`
- `comparison`
- `diagram`
- `code-trace`
- `steps`
- `mistakes`

`diagram` はJSONの `nodes[]` と `connector` から軽量なHTML図を生成する。横幅を超える場合は図内部だけ横スクロールする。

## 7. 実装済みアルゴリズムLesson

| Lesson | タイトル | 置換term |
|---|---|---|
| ALG-01 | アルゴリズムの表現と擬似言語トレース | 001〜003 |
| ALG-02 | 計算量とオーダの読み方 | 004〜012 |
| ALG-03 | 配列・リストとデータの持ち方 | 014〜017 |
| ALG-04 | スタック・キューと操作順 | 018〜020 |
| ALG-05 | ハッシュ表と衝突処理 | 021〜025 |
| ALG-06 | 探索アルゴリズム | 013, 026, 027 |
| ALG-07 | ソートを比較して理解する | 028〜036 |

合計 **36/65語分** を構造化Lessonへ置換済み。

### ALG-04

主な内容:

- stack / queue / deque
- push / pop / enqueue / dequeue
- LIFO / FIFO
- front / rear
- 循環キュー
- overflow / underflow
- 操作列トレース

### ALG-05

主な内容:

- hash table / hash function
- `k mod m` の具体計算
- collision
- separate chaining
- open addressing / linear probing
- 平均O(1)と最悪O(n)の区別

### ALG-06

主な内容:

- linear search
- binary search
- 整列済み前提
- left / mid / right の更新
- 番兵法
- O(n) / O(log n)

### ALG-07

主な内容:

- bubble / selection / insertion
- quick / merge / heap
- Shell sortを不足範囲として補完
- stable sort
- internal / external sort
- 計算量・安定性・追加領域・操作方法の比較
