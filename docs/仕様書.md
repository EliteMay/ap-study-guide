# AP Study Notes 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の個人学習用静的Webアプリ。

- 正本: GitHub `EliteMay/ap-study-notes`
- 主利用環境: GitHub Pages
- BUILD: `2026.08.30-r14`
- 基準: IPA 応用情報技術者試験 シラバス Ver.7.2
- 技術: HTML / CSS / JavaScript / JSON / PDF
- Server必須機能・秘密情報なし

現在は **旧1,422語監査完了 / 118Lesson / 短問91問 / 長文14Case42設問 / 2025春秋公開午後22大問Lesson Mapping済み** の段階。

## 2. 目的

1. 学習範囲を把握する。
2. 構造化Lessonで仕組みを理解する。
3. Lesson内確認問題で直後確認する。
4. 短問で知識を取り出す。
5. 長文Caseで複数情報を組み合わせる。
6. 最新公開公式問題で本番形式へ接続する。
7. 進捗Dashboardから弱点へ戻る。

優先順位: 操作性 → 分かりやすさ → 軽量性 → 保守性 → 見た目。

## 3. 崩してはいけない仕様

- 既存用語IDを不用意に削除・変更しない。
- localStorage Key変更時は移行処理を用意する。
- 既存過去問PDF / 問題JSON / 解説JSONの対応を壊さない。
- GitHub Pagesの相対Pathを維持する。
- API Key / Password等を公開Repoへ置かない。
- 監査済みIDの主Lesson割当を根拠なく変更しない。
- LessonはBase / Expansion indexをRuntime / CI双方で結合する。
- Practiceは`json/practice/practice-index.json`をRuntime正本とする。
- Caseは`json/cases/case-index.json`をRuntime正本とする。
- 2026 CBTの実問題を公開過去問として扱わない。
- 2025公開問題では旧名称「午前/午後」を保持し、現在名称「科目A/科目B」と区別する。
- 「23/23 Coverage」を「試験対策として完全」と表現しない。

### 現行2026年度の扱い

- APはCBT方式。
- 旧「午前」= 現「科目A」。
- 旧「午後」= 現「科目B」。
- 問う知識・技能範囲、出題形式、出題数・解答数、採点方式、配点、合格基準、試験時間は方式変更によって変更されない。
- **2026 CBTの実試験問題は非公開。**

### 最新公開フル問題

2025年度春期・秋期を利用する。

Mapping対象:

- 2025春期 午後 問1〜11
- 2025秋期 午後 問1〜11
- Total **22大問**

保存するのは:

- 問番号
- 分野
- 本サイトによるテーマ要約
- 必須/選択
- 主学習Unit
- 関連Lesson
- IPA公式掲載Page / 問題PDF URL

問題全文・設問全文は本Repoへ転載しない。

MappingはAP Study Notes独自分析であり、IPA公式の教材分類ではない。
