# AP Study Notes 仕様書

## 1. 概要

応用情報技術者試験（AP）の学習用静的Webサイトです。

GitHubリポジトリ `EliteMay/ap-study-notes` を正本とし、HTML/CSS/JavaScript/JSON/PDFで構成します。現在の構成は固定ではなく、学習効果・操作性・軽量性・保守性が上がるなら再設計して構いません。

## 3. 共通用語ページ

`security.html`、`network.html`、`database.html` は共通エンジンを利用します。

- ロジック: `js/term-page.js`
- スタイル: `css/term-page.css`

各HTMLは `window.TERM_PAGE_CONFIG` で表示名、マニフェスト、localStorageキー、ID接頭辞、相対パスを指定します。

共通機能:

- マニフェスト/JSON読み込み
- 用語一覧・カテゴリ目次生成
- リアルタイム検索・カテゴリフィルタ
- 詳細解説の遅延描画
- 用語間自動リンク
- URLハッシュから用語カードを開く
- 習得済みチェック・進捗表示・localStorage保存
- 無効になった古い進捗IDの整理
- 目次ハイライト
- 基本データ整合警告

## 4. 用語データ

### 軽量用語

保存先: `json/terms/`

主なフィールド: `id`, `term`, `aliases`, `category`, `definition`

### 詳細解説

保存先: `json/details/`

主なフィールド: `id`, `term`, `category`, `level`, `tags`, `beginner`, `example`, `examPoint`, `trap`, `deepDive`, `relatedConcepts`, `commonMistakes`, `afternoonUse`, `howToRemember`

用語JSONと `id`、`term`、`category` を対応させます。

## 8. セキュリティ過去問

### 表示

- HTML: `html/security-past.html`
- CSS: `css/past.css`
- JS: `js/past.js`

### データ

- 索引: `security-past-index.json`
- 問題文: `json/past-problems/`
- 解説: `json/past/`
- PDF: `sources/`

### 対応ルール

索引側: `file`, `problemFile`, `sourcePdf`

解説側: `sourceProblemFile`, `sourcePdf`, `sections`

問題文側: `problem.questions[].label`, `problem.questions[].targets`

解説 `sections[].answerTargets` と問題文 `questions[].targets` は同じ設問ラベルで一致させます。

### 互換対応

古い過去問データでフィールド名が揺れていても表示を壊しにくくするため:

- `studyChecklist` と `reviewChecklist` の両方を復習チェックとして扱う。
- `choices` は文字列配列と `{key,text}` オブジェクト配列の両方に対応。
- `answerGuide` がない場合は `sections.expectedAnswers` から最低限の答案ガイドを生成。
- 問題文JSONが読み込めない場合も、解説とPDFリンクは可能な範囲で表示する。
- 関連用語は辞書IDが見つかる場合だけリンク化する。

## 9. テスト

### 現行版

- HTML: `html/test.html`
- CSS: `css/test.css`
- JS: `js/test.js`

3分野の軽量用語JSONを直接読み込み、その場で4択問題を生成します。詳細解説JSONは通常テストでは読み込まず、初期読み込みを抑えます。

機能:

- 3分野ミックス / 分野指定
- 最大100問
- 説明→用語 / 用語→説明 / ミックス
- 同カテゴリ中心の選択肢
- 説明文内の正解語/別名を自動マスク
- 1〜4キー回答 / Enterで次へ
- 結果・間違い一覧
- 間違えた問題だけ再テスト
- 辞書カードへの復習リンク

### 旧版

`html/test-legacy.html`

旧テストの手作りAP本番風問題を失わないため一時保存しています。将来、良い問題だけを `json/test/` 等へ抽出して新テストへ統合した後、legacyページを削除できます。

## 10. 品質チェック

`tools/check-json.html`

用語系:

- 3分野のファイルcount / manifest総数
- 用語ID/詳細ID重複
- term重複
- 用語/詳細のID・term・category対応

過去問:

- 索引の解説ファイル
- `problemFile`
- `sourceProblemFile`
- `sourcePdf` パス情報
- `sections`
- `answerTargets`
- `expectedAnswers`
- 問題文 `targets` と解説 `answerTargets` の一致
- 問題文側の設問に解説漏れがないか

基本完了条件は `ERROR 0` です。

## 11. GitHub Pages

- ルート: `index.html`
- `.nojekyll` 配置済み
- ページ・JSON・PDFは相対パスで参照
- APIキーや秘密情報は置かない

想定URL: `https://elitemay.github.io/ap-study-notes/`

GitHub Pages側の公開設定・実ブラウザ動作は別途確認が必要です。
