# AP Study Notes 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の個人学習用静的Webアプリ。

- 正本: GitHub `EliteMay/ap-study-notes`
- 主利用環境: GitHub Pages
- 構成: HTML / CSS / JavaScript / JSON / PDF
- BUILD: `2026.08.30-r8`
- 状態: **機能基盤は利用可能 / 旧教材監査完了 / シラバス不足範囲を再設計中**

ページ数・用語数だけでは教材完成としない。

## 2. 目的と優先順位

AP合格に必要な知識を、単語暗記だけでなく計算・図・状態遷移・コード・SQL・通信フロー・Security Caseまで含めて理解し、問題へ適用できる状態にする。

優先順位:

1. 操作性
2. 分かりやすさ
3. 軽量性
4. 保守性
5. 見た目

## 3. 崩してはいけない仕様

- 既存用語IDと進捗対応を不用意に壊さない。
- localStorageキー変更時は移行処理を用意する。
- 過去問PDF / 問題JSON / 解説JSONの対応を壊さない。
- GitHub Pagesの相対パスを壊さない。
- 秘密情報/APIキーを公開リポジトリへ置かない。
- 監査済みIDの主Lesson割当を根拠なく変更しない。
- 旧用語の監査完了とAPシラバス全範囲完成を混同しない。

専用Hub:

| Lesson | 主内容 | 中分類 |
|---|---|---|
| CMP-01 | Container / Virtualization | 5 |
| CMP-02 | IaaS / PaaS / SaaS / Serverless | 4 |
| CMP-03 | CPU / Register / Instruction Cycle / Pipeline | 3 |
| CMP-04 | Memory階層 / Cache / Virtual Memory / TLB | 3,5 |
| CMP-05 | Bus / I/O / Interrupt / DMA | 3,6 |
| CMP-06 | OS / Process / Thread / Scheduling / Deadlock | 5 |
| CMP-07 | 3層構成 / Scale / Cluster / Load Balancer | 4 |
| CMP-08 | Clock / CPI / CPU時間 / MIPS / Throughput | 3,4 |
| CMP-09 | MTBF / MTTR / Availability / Reliability / Failover | 4 |
| CMP-10 | HDD / SSD / RAID / File System / Journaling | 3,5,6 |

計算・適用として最低限以下を含む。

- Cache実効Access時間
- Round RobinのCPU割当trace
- CPU実行時間 = 命令数 × CPI × Clock周期
- 周波数とClock周期の相互変換
- MTBF / MTTRからAvailability
- 直列/並列構成のReliability
- RAID 5容量

Computer Systems Hubは共有Shellナビから自動追加する。

## 8. `legacyTermRanges`

連続IDを大量に列挙せず範囲で保持できる。

```json
{
  "legacyTermRanges": [
    {"prefix":"net-dns-","from":1,"to":40}
  ]
}
```

CIで実IDへ展開し、未割当・重複を検出する。

| Service / Audit | 3 |

Security主教材はSEC-01〜12。

方針:

- 純粋な通信原理はNetworkへ移す。
- Securityでは攻撃・防御上の意味を扱う。
- 攻撃は名前だけでなく「成立条件 → 観測 → 影響 → 対策」で学ぶ。
- 暗号は目的から選ぶ。
- 認証はAuthentication / Authorization / OAuth / OIDCをFlowで区別する。
- Incident Responseは検知・封じ込め・根絶・復旧・事後改善を時系列で扱う。
